---
name: design-review
description: A structured design interview skill that sharpens vague ideas into requirements, architecture decisions, tasks, ADRs, and glossary entries.
---

Run a design-review session.

Rules:
1. Ask one question at a time (or use multiple-choice rounds).
2. Prefer inspecting project files over asking if the answer may already exist.
3. Challenge vague terms.
4. Convert decisions into ADR entries.
5. Convert new terminology into glossary entries.
6. End with updated tasks and acceptance criteria.
